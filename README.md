# Sales & Revenue Analysis Dashboard

## About
Built an interactive dashboard to analyze sales and revenue data using Python, Streamlit and Plotly.

## Features
- CSV data import and processing
- KPI cards: Total Sales, Profit, Orders, Products
- Revenue Trend Over Time (Line Chart)
- Sales by Category (Pie Chart)
- Top 10 Products by Sales (Bar Chart)
- Sales by Region (Bar Chart)
- Interactive filters for Year, Region and Category

## Tools Used
- Python 3.14
- Streamlit
- Plotly Express
- Pandas
- Dataset: Superstore Sales Dataset (Kaggle)

## How to Run
pip install pandas plotly streamlit openpyxl
streamlit run app.py

## Output

- Total Profit: $286,397
- Total Orders: 5,009
- Total Products: 1,850
